# NanoVNA Remote — User Manual / Benutzerhandbuch

| | English | Deutsch |
|---|---|---|
| Source (Markdown) | [manual_en.md](manual_en.md) | [manual_de.md](manual_de.md) |

The two files are the same manual in two languages: same chapters, same facts. **Any change that alters what a
user sees or does updates both in the same change** (rule 7 in `CLAUDE.md`). Describe behaviour from the code, not
from memory. The device display and the web pages are English only; the German manual names the English labels.

There is no built HTML/PDF yet; when releases start, build both from the Markdown (pandoc) and attach them to the
GitHub release.
