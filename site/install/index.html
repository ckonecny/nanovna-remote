Install the firmwareFirmware installieren

Straight from the browser, no tools to install. For the Adafruit ESP32-S3 Reverse TFT Feather (product 5691). Direkt aus dem Browser, ohne Programme. Für das Adafruit ESP32-S3 Reverse TFT Feather (Produkt 5691).

What you needWas du brauchst

  • The Feather and a USB-C data cable to your computer (the NanoVNA is not connected yet).Das Feather und ein USB-C-Datenkabel zum Computer (das NanoVNA ist noch nicht angeschlossen).
  • Chrome or Edge on a computer (or Chrome on Android with a USB-OTG cable). Firefox, Safari and iPhones cannot do this.Chrome oder Edge am Computer (oder Chrome auf Android mit USB-OTG-Kabel). Firefox, Safari und iPhones können das nicht.

1. Put the Feather in the bootloader1. Feather in den Bootloader versetzen

Hold the D0 button, tap RESET, then let go of D0. The display stays dark. D0 gedrückt halten, RESET kurz drücken, dann D0 loslassen. Das Display bleibt dunkel.

2. Install2. Installieren

This browser cannot flash. Use Chrome or Edge on a computer, or download the files.Dieser Browser kann nicht flashen. Nimm Chrome oder Edge am Computer, oder lade die Dateien herunter. Open this page over https.Öffne diese Seite über https.

Click Connect, pick the port of the Feather in the list (named like “USB JTAG/serial debug unit” or “ESP32-S3”), then choose Install in the window that opens. It takes about a minute. Connect klicken, in der Liste den Port des Feathers wählen (heißt etwa „USB JTAG/serial debug unit“ oder „ESP32-S3“), dann im geöffneten Fenster Install wählen. Das dauert etwa eine Minute.

3. Start3. Starten

  1. When it says done, press RESET once. The display shows the WiFi NanoVNA-Remote (password nanovna-remote).Wenn „fertig“ erscheint, einmal RESET drücken. Das Display zeigt das WLAN NanoVNA-Remote (Passwort nanovna-remote).
  2. Join that WiFi, open http://192.168.4.1/wifi and pick your network.Mit diesem WLAN verbinden, http://192.168.4.1/wifi öffnen und dein Netz wählen.
  3. Connect the NanoVNA to the Feather’s USB-C port and open the address shown on the display. More in the manual.Das NanoVNA an den USB-C-Anschluss des Feathers hängen und die Adresse vom Display öffnen. Mehr im Handbuch.
Note: installing writes the whole device and clears the saved WiFi networks (the calibration is not touched). For later updates no cable is needed: see chapter 7 of the manual. Hinweis: Die Installation beschreibt das ganze Gerät und löscht die gespeicherten WLAN-Netze. Für spätere Updates braucht es kein Kabel: siehe Kapitel 7 im Handbuch.
